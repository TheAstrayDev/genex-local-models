# Validation scope

This first public package uses a new publisher-prefixed identity. Evidence from the earlier local `local-models` prototype is labeled separately; it is not represented as clean stock-host acceptance of the public package.

## Public-package checks

- 26 TypeScript tests: route and argument boundaries, queues/cancellation, download integrity/archive paths, project-scoped asset restoration, continuation and runtime integration evidence.
- 13 Python tests: native RGBA prompts and read-only alpha validation, one bounded retry, model command boundaries, reference masks, failed paint handling and UV-split normal transfer.
- TypeScript checking and production build.
- Disposable real Genex registry: install, enable, harmless `status`/`assets` calls with one unchanged chat binding, all 14 file skills/four references, synthetic previous-version update preserving assignments, disable/remove withdrawal and retained storage. No inference, account access or real chat session is used by this fixture.
- Stock upstream validator: expected rejection of the 35-minute native recipe. This is an outstanding compatibility failure.

`scripts/check-host.ts` requires an explicit compatible host path through `GENEX_SOURCE_DIR`. It reports its evidence under ignored `.evidence/`. It does not silently patch a checkout or touch a normal app profile. `plugin:doctor` and official pack/submit commands require the same native-job budget extension to inspect this package. On the pinned current upstream checkout, `compat/inspection-budget.patch` is sufficient for these no-inference fixtures; their consent callback is synthetic and allows only status/assets reads. This does not prove app UI consent or Windows GPU sandbox acceptance.

## Earlier real inference on the local prototype

Windows x64, RTX 4070 12 GB, 32 GB RAM, local Genex 0.1.7-ui2 with native-job/retained-library extensions. Generated outputs were delivered through the host and workers exited sequentially. Examples include a native RGBA icon (76.0 s), native RGBA reference (46.4 s) and a balanced textured GLB (392.9 s). Cold starts vary with cache and disk.

A 200k-triangle High experiment took 449.4 s with 768px paint views. It added visible paint noise. A separate trained-512px repaint of the same shape/reference took 137.4 s and did not remove every defect. These are separate experiments; their sum/difference is not an end-to-end benchmark of the final preset. Final High keeps trained 512px views and remains opt-in. Surface-normal export tests preserved geometry, UVs and texture pixels.

The installed local prototype's 0.1.8 → 0.1.9 update retained model assignments and other plugins, and Genex reopened with a responding window. The `game-quality` skill and its references were read back from the installed package. No complete game quality benchmark establishes a model-to-model superiority claim.
