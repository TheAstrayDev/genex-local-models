# A cover must show the real game

Generated models, textures and music may enrich the game. Its Genex cover must be a real frame of that implemented game, not a Qwen-generated mockup presented as gameplay. Studio's sidebar cover and a public Genex gallery cover are different features.

When a game has reached a visual milestone or is about to be published, read `theastraydev-local-models__skill {"name":"genex-cover"}`. Use the available Studio/Genex capture workflow. Do not trigger generation on every turn or replace an owner-selected cover. When the user only brought a game to publish and asked to keep its code untouched, do not add a cover demo to it.
