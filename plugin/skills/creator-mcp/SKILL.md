# Creator tools and local models

Local generation uses `theastraydev-local-models__generate-image`, `theastraydev-local-models__generate-audio` and `theastraydev-local-models__generate-model`. Their returned files belong to the bound project. No Genex sign-in or credits are required for these local calls; model licenses still apply.

When available, the bundled `genex-creator__` tools remain useful for game or animation discovery. Read `genex__skill {"name":"creator-mcp"}` before using that integration. The presence of Local Models does not mean a Genex account is connected. Do not use remote creator generation or setup tools to replace local work, install another MCP, or sign in again.

Hosting, account state, player identity and purchases remain Genex platform functions. Local Models cannot impersonate these APIs. If their tools are absent, keep the local playable build working and report the missing platform integration.
